System Overview

GlobalSwift Logistics API provides real-time shipment tracking, delivery management, and logistics automation for enterprise clients worldwide.

REST API JSON Secure

Authentication

All requests require API key authentication.

GET /api/auth/login
Headers: API_KEY: your_key_here

Tracking API

GET /api/track/{tracking_id}
Returns real-time shipment location, status, and ETA.

Shipment API

POST /api/shipment/create
Used to create new shipment orders and assign tracking IDs.

Status Codes

200 - Success

400 - Bad Request

401 - Unauthorized

500 - Server Error
